FF RESOLUTION - build APK tanpa Android Studio (pakai GitHub)

1. Buat akun GitHub (gratis) lalu buat repository baru (New repository).
2. Ekstrak zip ini, lalu upload SEMUA isinya ke repository (Add file > Upload files),
   termasuk folder .github (kalau tidak ikut terupload, buat file baru
   dengan nama .github/workflows/build.yml dan isi dari file yang sama).
3. Buka tab Actions > pilih "Build APK" > tunggu centang hijau (sekitar 3-6 menit).
4. Klik run tersebut, bagian Artifacts, unduh "FFRes-apk", ekstrak, pasang file .apk.

CARA PAKAI
1. Pasang Shizuku, start lewat Wireless debugging.
2. Buka FF Resolution, beri izin Shizuku, pilih Free Fire / MAX, atur slider, TERAPKAN.
3. Tutup total Free Fire lalu buka lagi.
4. Tombol RESET mengembalikan game ke normal.

Butuh Android 12 ke atas, dan hasil tergantung merek HP.
